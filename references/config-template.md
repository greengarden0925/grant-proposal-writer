````markdown
## 八、合規檢查參數（給 scripts/compliance_check.py 讀取，與第二節保持一致）
```compliance
{
  "total_page_limit": 25,
  "section_page_limits": {"Research Plan": 13},
  "required_sections": ["研究計畫之背景", "研究方法", "預期完成之工作項目及成果", "參考文獻"],
  "reference_heading": ["參考文獻", "References"]
}
````

說明：
- `total_page_limit`：全文頁數上限；沒有上限填 `null`。
- `section_page_limits`：章節標題（部分字串即可）對應的頁數上限。章節的頁數，是從該標題所在頁算到下一個同級或更高層級標題所在頁。
- `required_sections`：必填章節標題（部分字串比對，不分大小寫）。
- `reference_heading`：參考文獻章節的標題候選。
- 程式只讀第一個 compliance 區塊。JSON 中不要寫註解。
