# 通用 profile（其他單位、校內計畫、無法辨識的計畫類型）

- profile 版本：1.0
- 最後查證日期：2026-10-12

## 何時使用

- 使用者選「其他」，例如校內計畫、基金會、醫院院內計畫、國外單位
- 指定單位的格式查不到時的保底

## 步驟 0 必做

1. 詢問單位名稱與計畫名稱，請使用者上傳徵求公告或範本。
2. 沒有檔案時，以 WebSearch 搜尋該單位當年度的徵求公告；找到後列出來源請使用者確認。
3. 仍找不到時，明確告知：「我找不到官方格式，將使用通用骨架。送件前必須依官方格式調整。」並在 config 標記。
4. 詢問使用者：年期、撰寫語言、頁數上限、經費上限（使用者不知道的項目標記「未查證」）。

## 章節骨架

使用 `writing-protocol.md` 的通用骨架。

## 官方審查面向

未知時，使用 `review-panel.md` 的通用架構（參考 NIH 簡化審查架構），並標明非該單位官方標準。

## 文獻數量建議（建議，非官方規定）

約每頁背景內容 2–3 篇。
