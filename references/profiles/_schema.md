# Profile 格式說明（給維護者與貢獻者）

每個 profile 描述一種計畫類型。分兩層：
- **穩定層**：章節骨架、審查面向、特殊必填內容、查證入口。逐年變動小，寫在 profile 內。
- **易變層**：頁數、年期、經費上限、截止日、研究重點、當年度是否徵求。profile 只記錄「最後一次查證的值」作為參考，**執行時一律重新查證當年度官方文件**。

## 必備欄位

```markdown
# <計畫類型名稱>

- profile 版本：
- 最後查證日期：YYYY-MM-DD
- 維護者：

## 查證入口
（官方網站、手冊下載處、建議的搜尋字串）

## 執行選項
- 年期：允許範圍（或固定值）；未查證時寫「未查證」
- 撰寫語言：
- 其他需詢問使用者的選項：

## 易變規定（最後查證值，執行時須重新查證）
| 項目 | 最後查證值 | 來源（網址＋文件年度） |

## 章節骨架
（官方要求的章節順序與各章重點）

## 頁數配置建議

## 官方審查面向與流程

## 特殊必填內容
（例如性別分析、資料安全監測計畫、推薦信）

## 審查小組調整
（對 review-panel.md 的角色增減或加重）

## 文獻數量建議
（必須標明「建議，非官方規定」或附官方來源）
```

## 撰寫原則

- 每一條規定都要附來源網址與文件年度；沒有來源的不寫，或明確標「未查證」。
- 不要把某一年的徵求重點寫成永久規定。
- 新增 profile 時，在 SKILL.md 的步驟 0 選單與 README 的支援清單加入。
