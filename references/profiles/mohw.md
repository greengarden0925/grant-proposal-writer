# 衛生福利部（含所屬署）科技計畫徵求案

- profile 版本：1.0
- 最後查證日期：2026-10-12
- 維護者：（請填入）

## 這個 profile 的性質

衛福部**沒有單一固定的計畫書格式**。每一個徵求案都有自己的「徵求說明書」或「需求說明書」，並在附錄附上該案的計畫書格式、作業要點與經費編列基準。因此本 profile 不提供章節骨架，只提供**找到並遵循該案格式的流程**。

範例（格式依附錄提供的已查證實例）：
- 衛福部「115–116 年度臺灣原住民族基因治理規範及健康政策應用先導計畫」徵求說明書：附錄一為計畫書格式，附錄二為補（捐）助科技發展計畫作業要點，附錄三為經費編列基準。
  - 來源：https://www.mohw.gov.tw/dl-102401-26f2238c-33a7-4684-9958-782114042bef.html
- 疾病管制署委託科技研究計畫需求說明書：附錄含研究重點、計畫基本資料表、計畫書格式、經費使用範圍及編列基準、人體研究法等。
  - 來源（106 年度範例）：https://www.cdc.gov.tw/En/File/Get/3L5M3B7sSmgF5uNmGPS72Q

## 步驟 0 必做

1. 詢問使用者申請的是**哪一個署或司、哪一個徵求案**，並請使用者上傳該案的徵求說明書或需求說明書。
2. 使用者沒有檔案時，以 WebSearch 搜尋 `衛生福利部 <年度> <計畫名稱> 徵求說明書`，或 `<署名> <年度> 委託科技研究計畫 需求說明書`。找到後列出網址與文件年度，請使用者確認是否正確。
3. 從說明書讀取並寫入 config：
   - 計畫書格式附錄（章節與表格）
   - 執行期限與年期
   - 經費上限與編列基準
   - 申請資格
   - 送件方式：份數、電子檔格式、截止時間與收件認定方式（各案不同，例如紙本份數與光碟電子檔的要求）
   - 審查方式與審查重點
   - 必附文件：例如利益衝突迴避檢核表、身分關係揭露表
4. 找不到該案的說明書時，**不得改用其他案的格式**，改用 `generic.md` 的通用骨架，並在 config 標記「未取得該案格式，送件前必須改依官方格式」。

## 執行選項

- 年期、語言、頁數：全部依該案說明書。說明書未規定的，詢問使用者，並標記為使用者決定。

## 已查證的共通事項（僅供參考，以各案說明書為準）

- 曾受該部委託或補助的申請者，應列出過去三年的計畫名稱作為審查參考。
  - 來源：衛福部「研發成果共享與資源加值計畫」徵求說明書 https://mohw.gov.tw/dl-91907-57c79532-55c2-4fc4-993e-3e6ff0b69039.html
- 審查方式：由該部就計畫內容遴聘相關專家進行書面或會議審核（同類徵求說明書常見的寫法）。
  - 來源：https://mohw.gov.tw/dl-92588-e84d47b9-a561-4ad0-94cb-7e3313c12d72.html

## 審查小組調整

- 衛福部徵求案多為政策或任務導向。① 領域專家改為「領域與政策專家」，加問：計畫內容是否逐項回應說明書列出的工作項目與預期成果？成果能否轉化為政策參考？
- 委託案（如疾管署）：主席加做「需求說明書工作項目逐項對照表」，確認每一項規格都有對應的內容。

## 文獻數量建議（建議，非官方規定）

依該案頁數規定估算；政策型計畫可納入政府報告與統計資料，但同樣須有可開啟的官方來源。
